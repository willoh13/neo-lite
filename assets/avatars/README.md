# Bot Avatar Pack

Six SVG avatars for your Telegram bot. Pick one, save it as a 512x512 PNG (most
image editors can export this), then send it to your bot via @BotFather's
`/setuserpic` command.

| File | Style | Best for |
|---|---|---|
| `jarvis-classic.svg` | Cyan concentric circles, JARVIS HUD aesthetic | The "I want a JARVIS feel" default |
| `minimal-dark.svg` | Dark with purple/blue gradient ring | Clean, professional, tech-forward |
| `cyan-orb.svg` | Glowing cyan orb with ripples | Mystical, AI-as-entity vibe |
| `friendly-gradient.svg` | Cyan-blue-purple gradient with smiley face | Casual, approachable, fun |
| `terminal-mono.svg` | Black/white monospace `>_` prompt | Developer, hacker, no-nonsense |
| `light-classic.svg` | White background, black "A" | Bright, corporate-friendly |

## How to use

1. Open the SVG in any image editor (browser, Inkscape, Figma, etc.)
2. Export as 512x512 PNG
3. Open Telegram, message `@BotFather`
4. Send `/setuserpic`
5. Pick your bot from the list
6. Upload the PNG

## Customizing

These are SVGs — open in any text editor and change the colors. Common tweaks:

- Want a different color than cyan? Find `stop-color="#00d4ff"` and replace with your hex code
- Want a different letter than "A" in `light-classic.svg`? Change `<text>A</text>` to your AI's first letter
- Want to add text? Wrap `<text>` in the right place with your AI's name

## Want more?

The pack is intentionally small. Once you pick a style, you can:

- Add your AI's name as text in the center
- Add a small badge (heart, star, lightning bolt) for personality
- Generate seasonal variants (snowflake for winter, leaf for fall)

Or just describe what you want to NEO and we can generate a custom one.
