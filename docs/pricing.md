# Pricing

NEO Operator itself is free and open source. No license, no rate limits, no monthly fees. Bring your own API key, run it on your own hardware, own the whole thing.

This page lists the things you can pay for *around* NEO Operator.

---

## White-Glove Setup — $2,499

See [`services.md`](./services.md) for the full breakdown.

**TL;DR:** 2-hour install session with Will over Zoom. You bring a Minisforum, leave with a working AI chief of staff on Telegram. Includes 60 days of support.

**Slot availability:** 4 per month. Waitlist opens when this month fills.

---

## Pro Skills Bundle — $79 (planned, not yet shipping)

A curated pack of 10–15 of Will's best custom skills, ready to install in one command.

```bash
neo-parts install pro-skills-bundle
```

**What's in it (target list, will evolve):**

| Skill | What it does |
|---|---|
| `autonomous-ai-agents` | Spawn and orchestrate sub-agents for parallel work |
| `devops` | Deploy, monitor, and roll back services |
| `github` | PR review, issue triage, repo health checks |
| `email` | Triage inbox, draft replies in your voice |
| `productivity` | Calendar + Notion + Drive workflows |
| `creative` | Design assets, infographics, ASCII art |
| `media` | YouTube → summaries, audio visualizations |
| `video` | Longform video → short viral clips |
| `mlops` | Local LLM stack management |
| `research` | Academic papers, market data, content monitoring |
| `social-media` | X/Twitter posting, monitoring, account ops |
| `smart-home` | Philips Hue + home automation |
| `note-taking` | Obsidian vault sync and search |

**Not yet shipping.** Will announces when it's ready. The plan is to bundle the skills, package them as a `parts/pro-skills-bundle/` add-on, and list on Gumroad. The free NEO Operator stays free — the bundle is the upgrade.

**Pricing model:** $79 one-time. Updates for life. New skills Will adds in the future get added to the bundle, you pay nothing extra.

**Why one-time and not subscription:** Will doesn't want to maintain a billing relationship. You pay once, you get the skills, you never see a renewal email. If Will stops maintaining the bundle, the source is on GitHub, you're not locked in.

## Hosted NEO — TBD, not for at least 6 months

The "Will runs it for you" tier. You don't install anything. You text a Telegram bot. Will pays the inference.

**Status:** not building this until the white-glove setup has been sold 10+ times and the Pro Skills Bundle has 50+ buyers. The point is to prove there's real demand before adding the operational overhead of a hosted product.

**Indicative pricing** (will change before launch):

| Tier | Price | What you get |
|---|---|---|
| Free | $0 | Telegram bot, 25 conversations/day, BYOK fallback |
| Pro | $29/mo | Unlimited conversations, your Notion/Drive/Gmail wired up |
| Team | $99/mo | 5 seats, shared Notion workspace, priority support |

**Why so far away:** Will has a day job and one Minisforum. Hosted NEO requires a model-rental budget, billing infrastructure, customer support, and uptime monitoring. That's a real company. Not building it on vibes.

## What you will never pay for

- NEO Operator itself
- The skill packs that ship with NEO Operator out of the box (`neo-operator-planner`, `neo-operator-researcher`)
- Reading the source code
- Forks and modifications
- Running it on your own hardware
- The Docker image

The only "monetization seams" are:
1. Will's time (white-glove setup)
2. Will's curated taste (Pro Skills Bundle — *which skills* are in the bundle is the value)
3. Will's inference bill (Hosted NEO, future)

Everything else stays free.
