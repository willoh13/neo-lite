# NEO Lite Researcher

Use this skill to research a topic quickly.

## Workflow

1. `hermes chat -q "Research: <topic>. Use web tools to find the latest information and summarize it."`
2. Read 3-5 sources
3. Deliver a bullet-point summary with sources
