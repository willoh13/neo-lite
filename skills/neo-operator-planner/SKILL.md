# NEO Operator Planner

Turn a vague goal into concrete next steps.

## Workflow

Tell NEO: "Help me plan: <your goal>"

NEO will:
1. Ask clarifying questions if needed
2. Break the goal into 3-5 milestones
3. List the first action for each
4. Track progress via the todo tool
